# 🎮 AstrBot 群聊圣经插件

> 基于 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的多关键词随机语录回复插件，让群聊充满欢乐与惊喜 ✨

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🔍 **多关键词触发** | 内置原神与本人两套圣经，支持自定义触发词 |
| 🎲 **随机回复** | 每组语录池随机抽取，每次回复都不重样 |
| ⏱️ **共享冷却** | 两组共用冷却时间，避免刷屏 |
| ⚡ **完全匹配免冷却** | 单独发送特定词时可跳过冷却，秒回不等待 |
| 🛡️ **群白名单** | 仅指定群聊启用，安全可控 |

---

## 🚀 快速上手

1. 将插件放入 AstrBot 插件目录
2. 在配置文件中启用插件
3. 修改配置中的触发词和语录（可选）
4. 重启机器人，开始享受圣经的洗礼吧！
